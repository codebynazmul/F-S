How Agro Cosmic Weave works

NASA data is collected and processed on a schedule in Supabase. The app only reads it; everything about the farmer stays in their own browser.

No account or sign-in: the farmer's name, farm and plans never leave the browser. NASA data enters only through the Edge Functions, which use the service key; the app uses the publishable key and can only read the public NASA tables.
